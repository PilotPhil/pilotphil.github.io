海冰三轴失效准则演示

把第一强度理论、Mises、Mohr–Coulomb 与 Tsai–Wu 四种失效准则放进同一个 σ₁–σ₂ 平面与三维主应力空间。调整拉压强度、拖动应力点，四种判据会同时给出结果。

  • 四种准则的实时判定与逐项数值代入
  • 二维包络线与三维失效面联动
  • 单文件部署，可离线打开

02 / 方向

四个方向，
一条线索。

从材料失效，到结构响应，再到把工具交给智能体。问题不同，方法相通：建模、计算、验证，然后把它讲清楚。

  1. 01

    冰力学与失效准则

    海冰在复杂应力状态下的强度与破坏。关注三轴试验、失效包络与多准则判据之间的一致性，也关心这些判据在工程尺度上是否仍然成立。

    Ice Mechanics
  2. 02

    结构动力学与数值仿真

    从模态、响应谱到瞬态响应。用数值方法把结构的动力行为拆开来看，再用实验或现场数据校对模型。

    Structural Dynamics
  3. 03

    DSH Plugin 工具链

    为 DeepSeek Harness 写插件：把重复的检索、整理、计算与检查收进可复用的工具里，让研究流程更顺手，也更少出错。

    Tooling
  4. 04

    Agent 与科研工作流

    探索智能体在文献调研、代码复现与结果核对中的角色。不是替代判断，而是把人的注意力留给真正需要判断的地方。

    Agent

03 / 关于

在力学与代码之间，
寻找可以复现的解释。

我关注材料与结构在复杂应力状态下的响应：从海冰的三轴强度与失效包络，到结构动力学中的模态与响应谱。

相比停留在公式里的结论，我更在意它能否被建模、被计算、被可视化，最后被验证。一个判断只有在边界条件说清楚、结果可以复现之后，才算真正站得住。

代码是实验的延伸。我用 Python / MATLAB 做计算，用 Three.js 把失效面搬进浏览器，也在探索 DSH Plugin 与 Agent 如何介入科研工作流——让重复的部分自动化，把判断留给人。

这个站点记录我正在做的事：一些已经可以运行的作品，一些还在整理中的想法，以及过程中写下的笔记。

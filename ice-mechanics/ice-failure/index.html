课堂演示说明

怎么用

  • 二维 / 三维：顶部开关切换第三维。σ3 关闭时锁定为 0，画面即任务书的双轴包络线；开启后 σ3 独立可调，包络线成为三维失效面在该平面的切片。
  • 改材料：右侧“输入条件”可调单轴拉伸 / 压缩强度 σt、σc 与剪切强度 S，四种准则的系数、包络线与三维失效面按新强度重新标定；点“恢复任务书”回到 0.8 / 4.0 / 1.0 MPa。
  • 改应力：拖右侧滑块、输入数值，或直接在二维图上拖动圆点。
  • 看判定：右表实时给出四种准则的 g 与结论；点任一行看公式代入。每行左侧的复选框可单独显示 / 隐藏该准则，图例同步；全部隐藏时点“显示全部”恢复。
  • 三维视角：拖动旋转、滚轮缩放、右键拖动平移；σ3 切片随滑块移动。

σt、σc、S 可在右侧“输入条件”中调整，四种准则的系数与包络线随之重新标定： F11 = 1/σt − 1/σc，G1111 = 1/(σtσc)， G1122 = G1111 − 1/(2S2)（由纯剪切状态 (S, −S) 定）； 三维的 F33、G3333、G1133 按任务书 v4 的比例取。 三维 Tsai–Wu 为横向各向同性：沿柱轴（σ3）的强度为水平方向的 2 倍， 默认取值下即 1.6 / 8.0 MPa。因此同一压缩应力沿 σ1 与沿 σ3 的判定不同——这正是三维演示要说明的各向异性。

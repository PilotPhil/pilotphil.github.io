# NDEM — 船冰接触力学演示站

**在线体验：<https://pilotphil.github.io/load-forecast/ndem/>**

纯静态页面，**无需构建、无外网依赖**，直接把整个 `ndem/` 目录上传到任意静态托管即可。

## 文件结构

```
ndem/
├── index.html        入口页（两张卡片，链接到下面两个页面）
├── simulation.html   一维落地仿真（交互）
├── derivation.html   完整公式推导（长文）
├── katex/            公式渲染库（本地化，离线可用）
│   ├── katex.min.css
│   ├── katex.min.js
│   └── fonts/        20 个 woff2 字体
└── README.md
```

## 部署

- 本仓库中部署在 `/load-forecast/ndem/`，保持**相对路径不变**（`derivation.html` 依赖 `katex/`）
- 入口是 `index.html`
- 推荐 https，KaTeX 字体走同源相对路径，不需要额外 CORS 配置
- 不需要 Node、不需要构建、没有后端

## 页面说明

### index.html
入口页。两张卡片分别通向仿真与推导。

### simulation.html
一维小球落地仿真。

- 左侧：Canvas 动画，球从可选高度落到地面
- 中间：四张曲线（穿透量 δ、力 F、速度 v、位移 y），共用时间窗
- 右侧：一步之内的八步数据流，每一步显示公式与**实时数值代入**

控件：单步（→）、连续（空格）、重置（R）、恢复系数 e（0–2）、落差 h、
"接触时暂停"、"静止后停止"。

URL 参数：`?step=N` 可直接停在第 N 个子步，例如
`simulation.html?step=37` 停在第一次撞地，`?step=420` 停在静置。

### derivation.html
完整推导长文，按章节连续滚动：

```
第 1 章 刚体的运动：6 个自由度
第 2 章 从牛顿定律到「冲量」
第 3 章 质量矩阵 M：I₃ 和 I 到底从哪来
第 4 章 约束函数 C(q)
第 5 章 求偏导：从 C 得到雅可比 J
第 6 章 从 J 到等效质量 m_eff
第 7 章 求冲量
第 8 章 多接触：为什么必须迭代
第 9 章 完整流程总结
附录 A 符号总表
附录 B 常见困惑速查
```

数学基础（点乘、叉乘、矩阵、行列式、三重积、链式法则等 20 个概念）**不单独占章节**，
而是作为橙红色虚线词嵌在正文里，鼠标悬浮弹出公式与解释。

页面右侧有随滚动高亮的目录，顶部有阅读进度条。

## 技术说明

- 单文件 HTML，样式与脚本内联，无框架
- 公式：KaTeX 0.16.9（本地副本）
- 数学悬浮卡片用 `<template>` 存放内容，按需克隆并渲染
- 打印样式已处理（打印时隐藏目录、进度条）

## 内容来源

推导内容对应仓库里的 LaTeX 讲义：

- `docs/impulse-derivation.tex`
- `docs/impulse-derivation.pdf`（31 页，A4）

如需改公式或补章节，建议先改 `.tex`，再同步到 `derivation.html`。


入口页顶部保留了一个「← 主页」链接，点击返回个人主页的冰载荷预报 tab。
